## Kernel optimisation progression

Isolated decode-attention kernel vs PyTorch SDPA (FlashAttention family) on Llama-3.1-8B attention shapes (32 Q / 8 KV heads, head_dim 128). `ratio` < 1.0 means our kernel is faster. SDPA sits near the memory roofline for exact attention, so the honest target for the dense kernel is parity, not victory -- the wins come from moving fewer bytes (FP8 KV, paged sparsity).
